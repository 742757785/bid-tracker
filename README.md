# 招标信息追踪 - Web版

这是一个基于Web的招标信息追踪应用，可以追踪广东省茂名市和阳江市的招标信息。

## 快速开始

### 方法一：直接打开（最简单）

1. 双击 `打开应用.bat` 文件
2. 应用会在浏览器中自动打开

### 方法二：启动本地服务器

1. 双击 `启动服务器.bat` 文件
2. 在浏览器中访问 http://localhost:8080

### 方法三：手机使用

1. 将文件上传到网络服务器
2. 用手机浏览器访问
3. 点击"添加到主屏幕"

## 功能特点

- ✅ 查看招标信息列表
- ✅ 按地区筛选（茂名/阳江）
- ✅ 按类别筛选（工程/货物/服务）
- ✅ 关键词搜索
- ✅ 收藏感兴趣的项目
- ✅ 查看详细信息
- ✅ 分享招标信息
- ✅ 离线使用（PWA）

## 添加到手机主屏幕

### Android手机：
1. 用Chrome打开应用
2. 点击右上角菜单（三个点）
3. 选择"添加到主屏幕"
4. 确认添加

### iPhone：
1. 用Safari打开应用
2. 点击分享按钮
3. 选择"添加到主屏幕"
4. 确认添加

## 转换为APK

如需将应用转换为APK格式，请查看 `APK转换指南.md` 文件。

推荐方案：
1. 使用 PWA Builder (https://www.pwabuilder.com/)
2. 使用 AppsGeyser (https://appsgeyser.com/)

## 数据来源

应用展示的数据包括：
- 茂名市政府网站
- 阳江市政府网站
- 广东省政府采购网
- 各级公共资源交易中心

## 技术说明

- 纯前端实现，无需后端服务器
- 使用LocalStorage存储收藏数据
- 支持PWA，可离线使用
- 响应式设计，适配各种屏幕

## 注意事项

1. 当前版本使用示例数据
2. 实际使用需要连接真实数据源
3. 建议定期刷新获取最新数据
